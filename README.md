# Forks in the Forecast

DSC 106 final project: an explorable explanation of regional warming under four CMIP6 emissions scenarios.
Team: Chaylen Nguyen-Tran, Jeffrey Kang, Peter Little, Jayleen Shang.

- `index.html`, `main.js`, `style.css`: the explorable (D3)
- `proposal.html`: our project proposal
- `data/climate_paths.csv`: processed CMIP6 regional warming data
- `analysis/`: preprocessing notebook and static figure code
